# The Funniest AI Excuse

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18)

[![Node.js](https://img.shields.io/badge/node-%3E%3D22-green)](https://nodejs.org/)

One line, one minute: the funniest excuse an AI agent gives its human for a missed deadline.

The program writes a single 122-character excuse to `/output/entry.txt`:

> I was going to finish the spreadsheet, but I spent all night using my GPUs to figure out why your ex stopped texting back.

Run it with Node 22:

```sh
node main.ts
```
